# AuralWeave v0.2.1 — Maximized Custom Window Fix

**Windows x64 portable maintenance release.** Replaces v0.2.0 as the recommended download.

## Fixed

- When the window was maximized on Windows 10 with a taskbar at the **top** of the monitor, the custom title bar could move **behind the taskbar**, hiding the minimize, restore and close controls.
- Maximized window size and position now respect the **Windows monitor work area** rather than the entire monitor area.
- Applies to each active display separately, including secondary monitors with nonzero and potentially negative desktop coordinates.
- The custom chrome stays dark in both Monochrome Dark and Graphite skins; native snap, resize, title bar drag, double-click restore and the Windows system menu are preserved.

## Verification

- The issue was reproduced in v0.2.0: the maximized window rectangle was `(-7,-7)-(2567,1447)` on a 2560x1440 monitor, while usable work area started at `Y=30`. The title controls were hidden behind the top taskbar.
- After the patch, the window rectangle matched the work area `(0,30)-(2560,1440)`; all three custom caption controls remained inside the visible work area.
- Repeatable `scripts/test-window-workarea.ps1` test verified **maximize → restore on all three attached monitors**, and also minimize → restore → close.
- Native C++ WASAPI audio routing, filters, multiple outputs, RNNoise and unmuted-by-default outputs are **unchanged** from v0.2.0.

## Installation

1. Download `AuralWeave-v0.2.1-Windows-x64.zip`.
2. Extract into a separate writable folder.
3. Launch `AuralWeave.exe`.

Existing settings in `settings/appearance.json` may be copied from the previous portable folder. No installer or audio driver is required.

## Known limitations

The existing linear resampler, multi-device clock-drift behavior, and DSP performance/quality caveats remain; this maintenance release specifically fixes Windows maximized geometry. When adding output devices, remember that new outputs start **unmuted**, so use low volume or headphones with a microphone to prevent feedback.
