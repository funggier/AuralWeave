# AuralWeave v0.2.0 — Native audio routing and filters

Windows x64 portable release. Extract the ZIP, then launch `AuralWeave.exe`.
The application does not install drivers or Windows services.

## Included

- Native C++ WASAPI audio routing (the only audio backend), with one
  physical/loopback input distributed to multiple audio outputs.
- Dark custom window, monochrome scrollbar/sliders, and Monochrome Dark /
  Graphite skins. Skin choice is saved locally in the portable folder.
- New official **white–silver/gray intertwined AN ribbon icon** with a
  transparent background, embedded in the EXE and shown in window chrome.
- **Unmuted by default:** outputs added with `+` start with Mute unchecked.
  New filters also start enabled. You can mute/bypass each instance as needed.
- Filters start empty and show direct routing. The `+` button adds a
  `Choose filter...` slot that remains inert until a kind is selected.
- Fully ordered Native filter chain; independently repeatable Gain, RNNoise
  Standard v0.1.1, Noise Gate, and Limiter filters.
- Move filters up/down, collapse individual cards, and use Collapse all /
  Expand all to change the visible control layout.
- Output dropdowns show the actual Windows device Name first, with sample
  rate/channel information in braces; no raw endpoint IDs in normal UI.
- START and STOP are the same button with state-dependent labels.

## Safety and usage

**Output devices now start unmuted.** This matches the requested default
but may create loud feedback if microphones are routed to nearby speakers.
Start at low hardware volume and prefer headphones when testing; mute any
destination that should remain silent before pressing START.

1. Unzip `AuralWeave-v0.2.0-Windows-x64.zip` anywhere writable.
2. Run `AuralWeave.exe` with `AuralWeave.Native.dll` in the same folder.
3. Choose a sound input, add one or more sound outputs, and check mute/gain.
4. Optionally add Filters; leaving the chain empty uses direct processing.
5. Press START, adjust the route, and press STOP to end.

## Compatibility and known limitations

- Windows 10 or newer, x64. Self-contained .NET 8 WPF UI plus native audio DLL.
- The Native engine supports mono/stereo Float32 or PCM16 mix formats; some
  multichannel or exotic endpoints are not supported.
- RNNoise currently includes only the **Standard** embedded model from Xiph
  v0.1.1. Other RNNoise model sizes, EQ, voice conversion, preset handling,
  and virtual audio drivers are not yet available.
- Native resampling uses linear interpolation, without a production-grade
  anti-alias filter. Multi-device clock drift and hotplug recovery still
  require more engineering.
- Noise Gate and Limiter are initial DSP implementations. Audible quality,
  filter reconfiguration clicks, and end-to-end latency have not been
  characterized across all hardware.
