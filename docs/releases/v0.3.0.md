# AuralWeave v0.3.0 — Windows x64 Portable Studio

Release date: 2026-11-25

**Scope: a normal Portable Studio release with Filter Presets and read-only
Virtual Driver management. It does NOT install or contain a Windows
Virtual Audio Driver.**

## What's included

- Native C++20/WASAPI real-time Sound Input -> ordered Filters -> Sound Output.
- Multiple simultaneous physical outputs, individual mute/gain and compact
  dark window with custom title bar and AN ribbon icon.
- Repeatable, reorderable RNNoise Standard, Noise Gate, Limiter and Gain filters.
- Filter Presets: Save/Load/Import/Export portable `.awfilter` JSON; devices
  are not serialized into presets.
- Virtual Driver page showing one Virtual Input and one Virtual Output
  installation state (Windows SetupAPI). The INSTALL action is disabled because
  there is no trusted, signed production driver.
- A more robust developer-only multi-Portable user-mode PCM bridge:
  contributors may mix into one bus; independent listeners each receive a
  copy of the audio. Its native transport now notices when the owning process
  exits unexpectedly and prunes stale users without disrupting surviving
  sessions. This facility is not exposed as a working Windows audio driver.

## Verification

- GitHub Actions on Windows successfully compiled and verified previous
  Virtual PCM/Studio commits, including cross-folder mixing and fanout.
- Windows 10 22H2 hardware host: Native and managed build, existing core
  checks, kernel PCM mock, user-mode multi-client checks and forced process
  termination recovery passed with Exit Code 0.
- The native virtual bridge uses an owner-only Windows event HANDLE that
  disappears when its process dies, even when attached peers hold Shared
  Memory mapping handles.
- Windows Portable publish creates `AuralWeave-v0.3.0-Windows-x64.zip`.
  The ZIP is audited to exclude unsigned kernel SYS/INF/CAT and debug binaries.
- Windows 11 is targeted at source/OS version level but **not runtime tested**.

## How to try

1. Download and extract `AuralWeave-v0.3.0-Windows-x64.zip` into any writable
   folder, e.g. `T:\\AuralWeave-Test`. No installer is required.
2. Run `AuralWeave.exe`.
3. Select an input, use headphones and low gain first, add one or more outputs
   and press **START**. Added outputs are unmuted by default: avoid feedback.
4. Try adding/reordering filters and Save / Load / Import / Export presets.
5. Open Virtual Driver to view status. It will not install unsigned drivers.

## Important limitations

- **No actual Windows virtual microphone/speaker** yet. Developer-only PCM
  mock tests are not evidence of kernel endpoint functionality.
- Do not install the WDK prototype, enable Windows Test Signing, disable Secure
  Boot or forcibly bind any unsigned AuralWeave INF/SYS to the host.
- Native resampling and independent device clock drift remain under
  improvement; exact round-trip audio latency has not been quantified.
- Production-grade broker authorization, kernel deployment/signing, hardware
  timer-driven audio and Windows 11 QA are pending.
