# AuralWeave v0.5.0 — Windows x64 Portable

- Added an ordered **VST Plugin** filter card for installed 64-bit VST2 audio effects.
- Browse or enter a custom folder, scan for DLLs, select an effect and open its editor.
- Stores the last scanned folder beside the application. Filter Presets restore VST cards as empty slots, ready for manual plugin selection.
