# AuralWeave v0.3.1 — Windows x64 Portable

## Changes

- Open directly to Sound Input, Filters, and Sound Output.
- Retire the experimental AuralWeave driver, setup helper and mock broker.
- Use Windows WASAPI endpoints for physical devices and independently installed virtual audio devices.
- Include the VB-CABLE setup guide in the release notes for routing audio to and from other apps.
