# AuralWeave v0.3.0-preview.1 — Studio Presets and Virtual Driver Manager

**Development preview, not a GitHub Release.** The published v0.2.1 remains the latest release.

## Studio mode

- Added a top-level mode selector, **STUDIO** and **VIRTUAL DRIVER**, in a matching monochrome style.
- The Studio mode preserves the Native C++ WASAPI audio path and existing Filter Chain.
- Added Filter Preset manager with SAVE, LOAD, IMPORT and EXPORT.
- Local Filter presets use `presets/filters/*.awfilter` next to the portable executable.
- An .awfilter preset contains only filter kinds, order, parameters and Enabled values. It **does not save or restore Sound Input, Sound Output, mute/gain of outputs, or device IDs**.
- Import/export file dialogs allow choosing any destination folder and filename.
- Repeatable filters remain independent when restored; each receives a new instance UUID.

## Virtual Driver mode

- One page with two clearly separated cards: **Virtual Input** (Windows microphone/recording endpoint) and **Virtual Output** (Windows speaker/playback endpoint).
- Read-only Plug and Play enumeration uses a reserved AuralWeave Hardware ID namespace, not the app's installation directory or a fuzzy name match.
- Supports listing multiple recognized devices and requesting removal of a specific, freshly verified device with explicit confirmation and Windows UAC elevation.
- **Important limitation:** No actual AuralWeave kernel virtual audio driver is bundled or installed by this build. INSTALL buttons are deliberately disabled. Installing a signed first-party driver, creating multiple independent virtual endpoints and bridging audio to Native WASAPI remains future development. An untested driver is never installed automatically.

## UI layout

- Added slightly more spacing between top-level mode buttons, between Filter Preset controls, and around the Virtual Input/Output cards.
- Switching skins does not change audio processing or preset content.

## Tests

- Desktop build: 0 warnings, 0 errors.
- 32 Filter/Core tests passed, including preset roundtrips and exclusion of device IDs.
- Windows UI automation: Studio/Virtual mode switching, both Virtual Driver cards, and PnP scan without errors.
- PnP hardware identity diagnostics: reserved namespace recognized, unrelated hardware IDs rejected; no virtual drivers detected on the test machine.

## Safety

AuralWeave remains portable; installed kernel drivers would not move with its executable. Driver installation/removal can require administrator privileges. This preview performs no driver installation and does not change Windows test-signing or security settings.
