# AuralWeave v0.4.1 — Windows x64 Portable

- Renamed the existing equalizer to **EQ (3 Band)** and added **EQ (5 Band)** and **EQ (7 Band)**.
- Each band starts at 0 dB and can be adjusted independently from −12 to +12 dB.
- Retired Pitch Shift and its bundled libraries. Loading a v0.4.0 preset skips that stage and preserves the order and settings of the remaining filters.
- Presets containing the new EQ types use schema 3. Existing schema 1 and 2 presets remain readable.
