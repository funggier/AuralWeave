# AuralWeave v0.1.0

**Initial Windows x64 release — Native C++ WASAPI audio routing**

AuralWeave is a portable Windows audio routing application with a dark desktop interface and a native C++ audio engine. Extract the ZIP and run `AuralWeave.exe` from the extracted folder.

## Included

- Real-time native WASAPI input capture from microphone/Line In and supported system playback loopback sources
- One input routed to multiple outputs simultaneously, each with gain and mute settings
- Output dropdown that excludes endpoints already selected in the current route; selection is returned when removed
- Native per-output event-driven render, bounded buffering and prototype sample rate conversion for differing output formats
- Bypass noise-processing path (no noise removal)
- Repeatable, ordered Gain effect instances with independent enabled/disabled states and gain settings
- Dark UI and one Start/Stop button
- No separate installer or audio driver installation

## Installation and use

1. Download **AuralWeave-v0.1.0-Windows-x64.zip**.
2. Extract all files to any writable folder.
3. Run `AuralWeave.exe` and keep `AuralWeave.Native.dll` beside it.
4. Select a capture source and add output devices with the `+` button.
5. Outputs start **muted** for safety. Start at low volume with headphones, then explicitly unmute.
6. Press **Start route**; the same button becomes **Stop route**.

## Important limitations

- **RNNoise, EQ, AI voice effects, preset management and virtual audio drivers are not implemented in v0.1.0.**
- Native audio supports mono/stereo Float32 or PCM16 shared-mode mix formats. Some devices or multichannel configurations may be unsupported.
- Linear interpolation resampling is an early implementation without production-quality anti-alias filtering.
- Long-duration device-clock drift, hot-plug recovery and per-sink fault isolation need further validation.
- Tester feedback indicated Native C++ latency was not perceptible, but no calibrated end-to-end latency measurements have been made.
- This version is an initial functional release, not an assurance of compatibility with every Windows audio device.
