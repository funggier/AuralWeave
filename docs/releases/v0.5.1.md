# AuralWeave v0.5.1 — Windows x64 Portable

- Filter Presets remember the selected VST2 DLL. Previously loaded copies of that DLL reopen when the preset is loaded. Missing DLLs restore as empty cards.
- A new VST card starts with an empty folder field and a **Choose VST plugins folder...** hint.
- Scroll over a filter or output slider to change it by its fine step. For example, EQ adjusts by 0.1 dB and output gain by 0.01x.
