# AuralWeave v0.4.0 — Windows x64 Portable

- Updated AuralWeave's Windows icon and both Studio logos from the new transparent artwork.
- Added a 3-band EQ with independent low, mid and high gain.
- Added a stereo-linked Compressor with threshold, ratio, attack, release and makeup gain.
- Added Pitch Shift from −12 to +12 semitones. It preserves audio duration and uses formant compensation. The 0-semitone setting bypasses the processor.
- Added preset schema 2 for the new settings, with continued support for existing presets.
- Negotiated shorter WASAPI shared-mode periods on supported devices.
