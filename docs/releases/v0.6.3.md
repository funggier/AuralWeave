# AuralWeave v0.6.3

- VST2 and VST3 editors use a single Studio-themed title bar with an inset close button. Dragging from the close button cancels the click.
- The Add Filter button is shorter, with a centered plus sign.
- The Studio header shows **NATIVE AUDIO ROUTING** beside the logo.
- The status bar shows measured capture frames per second as `frames per sec`.
