# AuralWeave v0.6.1

- **VST Plugin (Custom Location)** searches only the folder you choose and its subfolders.
- **VST Plugin (Common Files)** automatically discovers 64-bit VST2 and VST3 effects in standard Windows locations. Click **Re-scan** to refresh the list after installing plugins.
- **Reload Plugin** opens a fresh instance of the selected effect in the same card. Select another effect or format to replace the current one.
- Filter Presets remember the discovery source and the exact selected plugin. Existing VST presets use Custom Location.
