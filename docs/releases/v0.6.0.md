# AuralWeave v0.6.0 — Windows x64 Portable

- The VST Plugin card detects 64-bit VST2 DLLs and VST3 modules or bundles. The list shows each format separately, including when the same effect is installed in both formats.
- Scan includes the folder you choose and the standard Windows VST3 folder. Presets remember the exact file selected.
- The VST folder field follows the selected Studio theme. Scanning refreshes only its own card.
- Audio with matching sample rate and channel count now passes directly to the output buffer. Mixed-rate audio continues to use the native resampler, with less work when writing and reading the ring.
